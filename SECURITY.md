# Security and private data

Do not post credentials, session transcripts, profile directories, snapshots or unredacted screenshots in issues. File paths, organization IDs and email addresses can also identify people or private projects.

For a vulnerability, use GitHub's private vulnerability reporting when enabled. If it is unavailable, open an issue requesting a private contact without disclosing the exploit or any user data. Do not include sensitive details in a public issue.

The app stores sensitive data locally. Backups are not fully encrypted and desktop profiles may contain cookies and other authenticated application storage. Protect the macOS user account and use encrypted disk/backups. The app does not provide cross-machine credential export.

Desktop session transfer resets copied permissions and omits source connector settings, but shared project configuration and the destination account's tools still apply. Review permissions in Claude before resuming a session from another account.

No security audit or broad compatibility guarantee is claimed. Use only accounts and organizations you are authorized to access.
